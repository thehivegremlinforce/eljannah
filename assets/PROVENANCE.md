## Demo briefing clip

`shift-briefing.webm` was recorded from this project's own animated 3D store. `shift-briefing-indexed.webm` is the seekable version used by the player. The 12-second clip is silent, contains no real staff footage and was created for this demonstration. `shift-briefing.vtt` supplies the original briefing captions; the interface also provides the full transcript.
